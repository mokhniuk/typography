## Quotation

| Register | Levels, outermost first |
|---|---|
| display | `“…”`, `‘…’` |
| literary | as display |

A quotation nested deeper than the levels listed starts over from the first.

An apostrophe before a dropped-letter word is not a quotation mark: `'s`, `'m`, `'t`.

## Spaces

- One-letter words kept with the next word: none.
- Short words kept with the next word, in a title (the opt-in rule `space.short-word`): none.
- A no-break space between a number and %: no.
- A no-break space between a number and € after it: no.
- Abbreviations: no list.

## Notes

Quotes: Taaladvies.net (Taalunie) says there is no fixed rule: double marks were traditional, single are common now, one system consistently; for a quotation inside a quotation it gives double for the outer and single for the inner "of andersom". The pack sets `“…”` with `‘…’` inside, the pair the Wikipedia table gives as primary and secondary. The other system, `‘outer “inner” outer’`, and the traditional `„…”` with `‚…’` (nl.wikipedia calls `„…”` the Dutch double mark for speech) are read from the source but not set. Apostrophes: nl.wikipedia warns that a single quotation mark must not be confused with the apostrophe (’s morgens is not an opening quote). ’s and ’m are listed there and ’s and ’n on the Flemish Team Taaladvies page; ’t is not on any page read, it is added as the same kind of dropped-letter form (’t huis), not verified. ’n (’n feestje) is not set: the engine reads the elision n only as rock 'n' roll, so a lone ’n before a word is not protected. Percent: Team Taaladvies says it is usually written without a space (the Belgian standard NBN Z 01-002 asks for one, for exact-science fields), so percentSpace is off. Not implemented, not verified: the EU Interinstitutional Style Guide could not be read (its pages are scripted and gave no text); number format, sentence dash, abbreviations, one-letter words (none is a Dutch convention in any page read).
