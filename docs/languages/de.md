## Quotation

| Register | Levels, outermost first |
|---|---|
| display | `»…«`, `›…‹` |
| literary | as display |

A quotation nested deeper than the levels listed starts over from the first.

Read by where each mark stands, not only by shape: `»…«`, `›…‹` (turned the other way round from the usual guillemets).

An apostrophe before a dropped-letter word is not a quotation mark: `'em`, `'til`, `'till`, `'cause`, `'bout`, `'round`, `'tis`, `'twas`, `'cos`, `'n'`.

- A no-break space between a number and % or €: yes.

## Notes

The other German style, „outer ‚inner‘ outer“, is a literary profile that does not exist yet. Digits are grouped with a no-break space (number.group), as the Interinstitutional Style Guide sets for all languages; a point is not used for thousands. The decimal mark is a comma.
