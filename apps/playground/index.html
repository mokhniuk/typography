Switch a rule off to see what it does. Each name is also what typo --disable takes. The rules are grouped by what they are for, not by the order they run in.

Config

The switches on this page as a config. Paste it under the "typography" key of package.json (the typo command reads it), into a .json file for typo --config, or into defineConfig({…}) in your code. To try a project's config here, paste it (or its whole package.json) and apply it.
