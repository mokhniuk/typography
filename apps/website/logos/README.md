# Logos

The marks in the landing page's "Works with" strip are from [Simple Icons](https://simpleicons.org)
16.35.0, released under CC0 1.0. The brands, and their logos as trademarks, belong to their owners; the
strip names the tools the package works with and implies no endorsement. Each file is the icon as
Simple Icons ships it; the page draws it as a CSS mask in the muted text colour (`style.css`,
`figure[data-marquee]`), so it follows the light and dark theme.
