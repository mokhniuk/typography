Plain text in. Typeset text out.

Podiia Typography sets quotation marks by language and nesting level, dashes and number ranges, apostrophes, ellipses and no-break spaces, so the text you ship reads like text a typesetter touched. Nothing is marked up in your source.

Install

Package manager 
npm install @podiia/typography

Pre-release, {{version}}. The package reaches npm with 1.0. Until then, install a release tag from git (git above); the repository is private, so the machine needs SSH access to it.

What comes out

Straight quotes, hyphens used as dashes, three dots, a space where a line must not break. Every sentence below went through the engine, in its own language.

One function, or the whole pipeline

Give it a string and a language. It returns the string, set. It can also say what it did, rule by rule, so a change is never a mystery.

What it takes care of

{{rulesOn}} rules run by default and {{rulesOff}} more you switch on. Each has a page that says what it does and why.

Quotation marks
By language, nesting level and register, in all {{langs}} packs: the 24 official languages of the EU, Ukrainian and Swiss usage. American quotes are an option.
Dashes and ranges
Dialogue dashes, sentence dashes and en dashes in ranges such as 21–26 and 10:00–12:00.
No-break spaces
Between a number and its unit, initials and surnames, abbreviations, one-letter words, and before a dash.
Symbols
Arrows, ©, the minus sign, ×, degrees and fractions, where you asked for them.
Hanging punctuation
Opening and closing marks hang in the margin at any width, without measuring where lines break.
Markup aware
HTML, Markdown and rehype modes leave tags, attributes, links and code exactly as they were.
