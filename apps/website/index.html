@podiia/typography {{version}} · pre-release

Real quotation marks, dashes and spaces, in {{langs}} languages.

A library that fixes the typography of running text. Give it a string and a language. It gives the string back with the right quotation marks, dashes where there were hyphens, an ellipsis, and no-break spaces where a line should not break. Tags, links and code are left alone.

Install

Package manager 
npm install @podiia/typography

Not on npm yet; it will be there at 1.0. Until then, pick git and install a release tag. The repository is private, so the machine needs SSH access.

03

Using it

One function takes a string and a language. The other entry points do the same for HTML, Markdown, rehype trees, React and the DOM.

import { typographic, explain } from '@podiia/typography';

typographic('He said "we\'re here" - and left.', 'en', { quoteStyle: 'us' });
// He said “we’re here” — and left.

explain('He said "hi"... 21-26', 'en', { quoteStyle: 'us' }).changes;
// quote “ · quote ” · ellipsis … · dash.range –

04

What isn't finished

Before you depend on it, you should know where it is weak.

  • No language has been read by a native speaker. The packs follow published style guides, and some of those we could only read in part. Each language page lists what it was written from.
  • Where the engine and Unicode's CLDR disagree about quotation marks (English, German, French, Swiss German), the decision record says so, instead of choosing quietly.
  • English sets « » by default. That is this project's house style. Pass quoteStyle: 'us' for “ ”.
  • Some input can't be read with certainty. An inch mark inside a quotation (a 5" hole) is one. Such cases are listed as limits, not guessed at.
