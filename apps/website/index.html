Real quotation marks, dashes and spaces, in {{langs}} languages.

A library that fixes the typography of running text. Give it a string and a language, and you get the string back with the right quotation marks, real dashes where there were hyphens, an ellipsis, and no-break spaces where a line should not break.

Install

Package manager 
npm install @mokhniuk/typography

Version {{version}}, on npm. It is compiled ESM with TypeScript declarations and has no dependencies. The command line runs on Node 20.10 or later, or on Bun. A minor release may change output, so read the changelog before you move up.

What it does

The engine is one function over a string. Everything else is a way to get your text into it, or to see what it did.

Every format your text lives in
Plain text, an HTML string, a Markdown document, a rehype or hast tree, a markdown-it plugin, React components, a Vue directive, and a command line for files and CI. One engine under all of them. For the browser, a DOM entry hangs the punctuation and checks which characters the page's font can draw. The API
A pack per language, and no default rule that names one
Quotation marks and how they nest, the dash, the spacing habits, the one-letter words that may not end a line: each is data in a language pack, which is why adding a language is one pack file. One opt-in rule still has a case for one language: the English labels (Type C, Vitamin C) that the degree sign leaves alone. The French space before : ; ! ? is a pack field too. The languages
Two registers
Display text is the default: interfaces, marketing, event pages. The literary register sets book-like text, and so far only English has one: British quotes, ‘…’ with “…” inside, and a spaced en dash. A dash for a line of dialogue is set in both registers, where the language writes dialogue that way.
It tells you what it changed
explain returns every change with the rule that made it and the text before and after, so a surprise is a question with an answer, not a mystery. The rules
Hanging punctuation, measured
An opening mark hangs into the left margin so the first letter lines up with the lines under it, and a closing mark hangs into the right. Each mark's width is measured in the browser once, and again when the web fonts load. Line breaks are never measured. How it works
It knows what your font cannot draw
A rule that would insert a character the font cannot draw leaves that stretch of text as you typed it, and the rest of the line is still set. A straight quote is better than a box. A quotation keeps both its marks or neither. In React the list fills itself from the page's own font (TypographyRoot, avoidMissing); …/dom exposes the measure. The font checker
Safe on what is not prose
Web addresses, emails and code spans come back byte for byte; tags, attributes and the contents of pre and code are never touched. An unknown rule name throws instead of passing quietly.
Proved, not promised
Property tests run seeded random text in every language: no letter or digit is lost or added, and a second pass changes nothing. A differential harness checks that a speed change rewrote no output. Known limits

Other languages

Each language has its own pack: its quotation marks and how they nest, its dash, its habits with spaces. These four are not translations of one sentence. Each is set the way that language is written.

Using it

One function takes a string and a language. The other entry points do the same for plain text, HTML, Markdown, rehype and markdown-it pipelines, React and Vue, and bring the browser side: hanging punctuation and font checks.

import { typographic, explain } from '@mokhniuk/typography';

typographic('He said "we\'re here" - and left.', 'en', { quoteStyle: 'us' });
// He said “we’re here” — and left.  (a no-break space before the dash)

explain('He said "hi"... 21-26', 'en', { quoteStyle: 'us' }).changes;
// quote “ · quote ” · ellipsis … · dash.range –
ImportFor
@mokhniuk/typographyA string. explain lists each change and the rule behind it.
…/textPlain text, a paragraph at a time. Line breaks are kept.
…/htmlAn HTML string. Tags and code are untouched.
…/markdownA Markdown document.
…/rehypeA unified or rehype pipeline, or any hast tree.
…/markdown-itA markdown-it plugin: every inline token is typeset as a block, links and emphasis are gaps, code is left alone.
…/reactTypeset and TypographyRoot, with hanging punctuation. TypographyRoot measures the page's font and fills avoid. A server component in Next.js can import them directly.
…/vueThe v-typography directive, which typesets an element in the browser on mount and on update.
…/domHanging punctuation in the browser, without a framework, typesetElement for a DOM subtree, and which characters the page's font can draw.
…/liteOne language only: the engine and the text, HTML and Markdown modes with no pack, and the page imports its pack from …/lang/<code>.
typoThe command line, for files and CI. Node 20.10 or later, or Bun.

In design tools

The Typography plugin for Figma runs the same engine over text layers, in the right-click menu. A Penpot plugin is next.

  • Format selection or the whole page. Quotation marks by language, dashes and no-break spaces are written back into each text layer (the Figma plugin works this way; Penpot's will follow it). The settings panel has the language, the register, the quote style and a checkbox per rule, and every run ends with a toast that counts the fixes and offers Undo.
  • Styling survives. The plugin applies only the inserted and deleted characters, so font, size and colour set on ranges of a layer stay as they were.
